# Rust Raid Calculator Bot

Telegram-бот для расчета рейдов в игре Rust. Позволяет определить самый выгодный способ разрушения конструкций, рассчитывает полный список необходимых ресурсов и выдает пошаговый план крафта.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Telegram](https://img.shields.io/badge/Telegram-Bot-blue)
![PyTelegramBotAPI](https://img.shields.io/badge/pyTelegramBotAPI-4.14%2B-green)


## Функционал

- Расчет стоимости рейда в чистой сере.
- Поддержка комбинированных способов (например, C4 + разрывные патроны).
- Пошаговый план: расчет фарма серы и угля, создание пороха и финальный крафт.
- Удобное меню с inline-кнопками для навигации.
- Справочник рецептов для C4, Ракет, Сачелей и патронов 5.56.
- Поддержка работы через SOCKS5-прокси (для использования с Tor).

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/gleb555-67/Rust-Raid-Calculator-Bot
   cd Rust-Raid-Calculator-Bot
   
2. Откройте файл bot.py и замените строку с токеном:
   
TOKEN = "..."

3.Настройка прокси (опционально).

Если вы используете Tor, в файле bot.py уже добавлена настройка прокси:   apihelper.proxy = {'https': 'socks5://127.0.0.1:9150'}
Перед запуском бота убедитесь, что клиент Tor запущен и слушает порт 9150. Если прокси не используется, закомментируйте эту строку.

4.Напишите в консоль:
   ```bash
   pip install -r requirements.txt
